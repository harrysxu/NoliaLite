## 5. 本轮发现与修复

- 文档模式移除常驻新建、打开、保存和更多按钮，文件操作收敛到原生菜单、快捷键和空状态入口。
- macOS overlay 标题区缩至 `38px`，只显示弱化文件名与必要状态；Windows/Linux 使用原生标题栏，不叠加 WebView 标题区。
- 编辑画布扩至最大 `880px`，减少顶部留白，并让可编辑区域延伸到视口底部以支持沉浸式输入。
- 新增 `docs/MARKDOWN_ELEMENT_SHOWCASE.md` 页面级验收语料，覆盖三类表格、H1-H6、嵌套行内格式、列表、引用、代码、图片、公式、HTML、脚注、Frontmatter、protected source、流程图和时序图；未修改时逐字节往返通过。
- 表格由强制 `100% + fixed layout` 改为内容优先的自动列宽；短表不再平均拉满正文，单元格收紧为 `6px 9px`，宽表只在自身 wrapper 中横向滚动。
- 对齐跨平台正文字体栈，补入 Segoe UI、Microsoft YaHei 与 Noto Sans 回退；正文改为 `16px / 1.68`，同时收紧段落、标题、引用、代码和分隔线的纵向节奏。
- 对照 Nolia 新增标题和行内格式局部 Markdown 编辑态；可直接修改标题 `#` 等级以及粗体、斜体、删除线、行内代码包裹符，Enter/失焦提交，Escape 取消。
- 对齐 Nolia 的链接契约：普通点击已有链接在正文原位置显示完整 `[文本](地址)`，保留 label 内嵌套格式；`Command/Ctrl+Click` 才导航，`Command/Ctrl+K` 新建链接继续使用“文本 + 链接”两字段表单。
- 补齐引用、无序列表、有序列表和任务列表的原位 Markdown 编辑；列表标记可在四类结构之间转换，任务复选框仍保持直接勾选。
- 脚注引用重命名会在同一事务内同步脚注定义；行内公式的非法定界符会阻止 Enter 和失焦提交。
- 相对 Markdown 链接经 Rust 解析真实路径并限制在当前文档目录内，支持目标文档锚点；不存在、非 Markdown、绝对路径和越界目标均拒绝打开。
- Lite 内部复制和无 HTML 的 Markdown 纯文本粘贴会恢复文档结构；外部富文本仍按安全边界降为纯文本。
- 表格源码支持失焦提交；代码语言别名与 Nolia 对齐，包括 `js`、`ts`、`zsh`、`yml` 等规范化值。
- 文件菜单“PDF…”改为直接生成文件：保存对话框确定路径后，macOS 使用 WKWebView/NSPrintOperation、Windows 使用 WebView2、Linux 使用 WebKitGTK 静默输出；临时 PDF 校验后原子替换，不引入 Chromium、Pandoc、Office 或网络转换服务。
- 修复 Tiptap 在 WebKit 并发提交前销毁未挂载 view 导致文档白屏的问题；编辑器改为提交后创建，并增加可恢复错误边界。
- 修复只读文档仍可通过复杂块、表格、代码语言、链接和命令式编辑入口修改内容的问题。
- 修复只读 Mermaid 查看导致编辑器尾部新增空段落的问题；只读扩展不再启用 trailing node，查看器不改变选区。
- Mermaid 普通点击/Enter 在只读模式不再进入源码，修饰键查看仍保留。
- 补齐模态 `aria-describedby`、初始焦点和 Tab/Shift+Tab 焦点约束。
- 修复原生关闭请求只销毁 WebView、主进程继续持有单实例锁的问题；关闭现在经过未保存文档守卫并明确退出应用。
- 修复 Finder/LaunchServices 冷启动路径未可靠进入前端的问题；路径先进入 Rust 队列，再由前端握手消费。
- 原生监听器改为隔离注册，拖放等次要监听失败不再阻断待打开文档的消费；应用级通知改为主窗口定向通知。
- 新增多窗口文件流程：系统文件多选、多文件拖放和 Finder 后续打开会创建独立窗口；窗口注册表隔离待打开路径、当前文件与监听器，重复路径聚焦已有窗口，`Command+Q` 逐窗执行未保存保护。

以上缺陷均已加入回归测试。
