## 5. 本轮发现与修复

- 删除居中首页，未打开文档时改为左侧历史面板，支持删除单条和清空最近记录；文档模式继续将文件操作收敛到原生菜单和快捷键。
- macOS overlay 标题区缩至 `38px`，只显示弱化文件名与必要状态；Windows/Linux 使用原生标题栏，不叠加 WebView 标题区。
- 编辑画布扩至最大 `880px`，减少顶部留白，并让可编辑区域延伸到视口底部以支持沉浸式输入。
- 新增 `docs/MARKDOWN_ELEMENT_SHOWCASE.md` 页面级验收语料，覆盖三类表格、H1-H6、嵌套行内格式、列表、引用、代码、图片、公式、HTML、脚注、Frontmatter、protected source、流程图和时序图；未修改时逐字节往返通过。
- 表格由强制 `100% + fixed layout` 改为内容优先的自动列宽；短表不再平均拉满正文，单元格收紧为 `6px 9px`，宽表只在自身 wrapper 中横向滚动。
- 对齐跨平台正文字体栈，补入 Segoe UI、Microsoft YaHei 与 Noto Sans 回退；正文改为 `16px / 1.68`，同时收紧段落、标题、引用、代码和分隔线的纵向节奏。
- 对照 Typora 重构连续所见即所得编辑：标题、段落、引用、列表、代码块等普通点击保持真实光标，光标进入标题或行内格式时显示语法标记，不进入局部源码输入框。
- 对齐新的链接契约：普通点击已有链接立即导航，`Command/Ctrl+Click` 在新窗口打开相对 Markdown 文档，当前文档锚点滚动，`Command/Ctrl+K` 使用“文本 + 链接”两字段表单。
- 新增 `Command/Ctrl+/` 全文 Markdown 源码模式；源码模式和所见即所得模式共享同一份 Markdown 状态，退出后重新解析画布。
- 新增代码块复制按钮和 `Command/Ctrl+Shift+C` 快捷复制；复制后按钮显示已复制状态。
- 新增图片选择、拖入和粘贴导入；图片复制到当前文档同级 `assets/`，Markdown 使用相对路径并自动处理同名文件。
- 脚注引用重命名会在同一事务内同步脚注定义；行内公式的非法定界符会阻止 Enter 和失焦提交。
- 相对 Markdown 链接经 Rust 解析真实路径并限制在当前文档目录内，支持目标文档锚点；不存在、非 Markdown、绝对路径和越界目标均拒绝打开。
- Lite 内部复制和无 HTML 的 Markdown 纯文本粘贴会恢复文档结构；外部富文本仍按安全边界降为纯文本。
- 表格源码支持失焦提交；代码语言别名与 Nolia 对齐，包括 `js`、`ts`、`zsh`、`yml` 等规范化值。
- 文件菜单“PDF…”直接生成文件：macOS 使用异步 `WKWebView.createPDF` 捕获完整文档矩形，Windows 使用 WebView2，Linux 使用 WebKitGTK；导出布局排除标题栏、状态和编辑浮层，临时 PDF 校验后原子替换，不引入 Chromium、Pandoc、Office 或网络转换服务。
- 修复 Tiptap 在 WebKit 并发提交前销毁未挂载 view 导致文档白屏的问题；编辑器改为提交后创建，并增加可恢复错误边界。
- 修复只读文档仍可通过复杂块、表格、代码语言、链接和命令式编辑入口修改内容的问题。
- 修复只读文档仍会处理 Markdown 纯文本粘贴的问题；只读编辑器不再接管或修改粘贴内容。
- 修复另存为后编辑器仍持有旧文件路径和读写扩展的问题；文件路径或权限变化时按当前会话重建编辑器。
- 修复本地图片可通过 `..` 或符号链接越出文档目录读取的问题，并补齐路径越界回归测试。
- 修复顶层代码块节点选中时快捷复制失效、链接表单可绕过危险协议校验的问题。
- 修复文件监听切换、重复关闭请求和保存路径选择期间的异步竞态。
- 修复只读 Mermaid 查看导致编辑器尾部新增空段落的问题；只读扩展不再启用 trailing node，查看器不改变选区。
- Mermaid 普通点击/Enter 在只读模式不再进入源码，修饰键查看仍保留。
- 补齐模态 `aria-describedby`、初始焦点和 Tab/Shift+Tab 焦点约束。
- 修复原生关闭请求只销毁 WebView、主进程继续持有单实例锁的问题；关闭现在经过未保存文档守卫并明确退出应用。
- 修复 Finder/LaunchServices 冷启动路径未可靠进入前端的问题；macOS `kAEOpenDocuments` 在 Tauri runtime 创建前注册，路径先进入 Rust 队列，主窗口创建后再由前端握手消费。
- 原生监听器改为隔离注册，拖放等次要监听失败不再阻断待打开文档的消费；所有窗口级通知按当前窗口 label 定向发送。
- 新增多窗口文件流程：系统文件多选、多文件拖放和 Finder 后续打开会创建独立窗口；窗口注册表隔离待打开路径、当前文件与监听器，重复路径聚焦已有窗口，关闭只销毁目标窗口，`Command+Q` 逐窗执行未保存保护。
- macOS 窗口子菜单使用 Tauri 保留的 Window Menu ID，在主菜单安装后由 AppKit 自动维护文档标题列表；实测两个窗口可从菜单直接切换。
- 修复 Tauri 窗口事件广播导致的跨窗口误关闭、误响应；打开路径、菜单、文件监听、关闭和退出事件均按窗口 label 定向发送。
- 修复 macOS 同步打印导致应用卡死，以及初版异步 PDF 只捕获当前视口、带入标题栏的问题；现在异步写入完整文档并在返回后恢复编辑布局。

以上缺陷均已加入回归测试。
