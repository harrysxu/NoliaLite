# Nolia Lite 测试与发布

> 版本：1.0.0
> 最近执行：2026-08-16
> 依据：[产品需求](./PRODUCT_REQUIREMENTS.md)、[UI/UX 规格](./UI_UX_SPEC.md)、[技术方案](./TECHNICAL_DESIGN.md)
> 首发平台：macOS arm64 / x86_64

## 1. 目标

测试覆盖多窗口单文档流程、所见即所得编辑、Markdown 保真、文件安全、原生系统集成、导出和发布产物。自动化测试验证可重复契约，Computer Use 验证最终安装版中的真实页面和原生交互；两者不能互相替代。

结果状态：

- `PASS`：已执行并满足预期。
- `FAIL`：已执行但不满足预期。
- `PARTIAL`：已覆盖主要路径，仍有明确的原生或性能项目待签收。

## 2. 质量门禁

每个发布候选依次执行：

```bash
npm run verify
npm audit --omit=dev
cargo fmt --manifest-path src-tauri/Cargo.toml --check
cargo clippy --manifest-path src-tauri/Cargo.toml -- -D warnings
npm run tauri:build
npm run test:release
```

任一类型检查、测试、审计、格式、静态检查或构建失败时，不得进入发布签收。

## 3. 自动化范围

| 范围 | 核心断言 |
|---|---|
| 文档状态机 | clean/dirty/saving/conflict/missing/error 状态正确，保存竞态不丢内容 |
| 文件流程 | 新建、打开、多选、拖放、Finder 打开、另存为、多窗口和逐窗口关闭正确 |
| Markdown 保真 | LF/CRLF/BOM、Frontmatter、未知语法和未修改块逐字保留 |
| 连续编辑 | 标题、粗体、斜体、删除线、行内代码、链接和全文源码模式行为一致 |
| 复杂内容 | 图片、表格、代码、公式、脚注、安全 HTML、Mermaid、流程图和时序图可编辑并往返 |
| 文档大纲 | 提取 H1-H6、层级缩进和点击跳转正确，跳转不产生编辑事务 |
| 只读与安全 | 只读入口不能修改内容；脚本、事件、远程资源和无效本地路径被拒绝 |
| 导出 | HTML 可独立打开；PDF 由系统 WebView 生成；导出不改写源 Markdown |
| 大文档 | 2 MB、10,000 行语料解析与组合在工程预算内 |
| 发布产物 | `.app`、DMG、图标、文件关联和本地前端资源完整 |

固定页面语料使用 [Markdown 全元素验收](./MARKDOWN_ELEMENT_SHOWCASE.md)。它覆盖标题、嵌套行内格式、列表、三类表格、代码、图片、公式、HTML、脚注、受保护语法、流程图和时序图。

## 4. 原生验收清单

使用 release `.app` 执行：

| ID | 操作 | 预期 |
|---|---|---|
| N-01 | 启动应用 | 默认窗口正常；无文档时显示历史面板 |
| N-02 | 打开含 H1-H6 的文档 | 宽窗口显示左侧大纲，点击标题准确跳转且不修改文档 |
| N-03 | 操作粗体、斜体、链接和行内代码 | 光标、语法标记、导航和快捷键行为正确 |
| N-04 | 操作 HTML 与代码块 | 正确高亮；聚焦后显示语言和复制控件，不误判为受保护 HTML |
| N-05 | 操作普通表格与超宽表格 | 普通表格使用正文宽度并自然换行，超宽表格仅局部横向滚动 |
| N-06 | 操作图片、公式、脚注和安全 HTML | 局部编辑正确，错误内容保留，脚本不执行 |
| N-07 | 操作 Mermaid、流程图和时序图 | 渲染、源码、查看器、缩放、复制和导出正常 |
| N-08 | 等待自动保存后重新打开 | 内容一致，保存状态正确 |
| N-09 | 未修改文档直接关闭 | SHA-256 和 mtime 不变化 |
| N-10 | 多选、重复打开和独立关闭文件 | 每份文件使用独立窗口，重复路径聚焦已有窗口 |
| N-11 | 制造外部修改、删除和保存冲突 | 不静默覆盖，重载、另存为和明确覆盖路径正确 |
| N-12 | 导出 HTML 和 PDF | 产物完整且不包含应用外壳或编辑浮层，源 Markdown 不变化 |
| N-13 | 检查 560x480、940x720、1440x900 | 控件不重叠，窄窗口隐藏大纲，正文和浮层不溢出 |
| N-14 | 切换浅色、深色和高对比度 | 正文、代码、表格、状态与焦点清晰可读 |
| N-15 | 强制结束、断网和大文档操作 | 草稿可恢复，无运行时网络请求，启动、输入和滚动达到预算 |

原生签收需记录截图、源文件哈希与 mtime；性能项目需记录设备、样本和测量方式。

## 6. 发布条件

- 所有自动化门禁通过。
- 无 P0/P1 数据丢失、安全绕过或只读写入缺陷。
- N-01 至 N-15 全部执行，且没有未解释的失败。
- 安装包小于 25 MB，空闲内存和启动时间达到产品预算。
- 文档、版本号和发布产物保持一致。
