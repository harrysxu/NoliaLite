# Nolia Lite 图标规范

> 版本：1.0  
> 母版：`src-tauri/icons/app-icon.svg`

## 1. 设计定位

Nolia Lite 与 Nolia 使用同一家族识别：深色 `N` 骨架和从青绿过渡到蓝色的对角笔画。Lite 版本通过更轻的笔画、更多留白和接近纸张的中性底色区分完整版，表达单文档、安静和轻量，而不是工作站或知识库。

图标不使用文档折角、文字行、`MD`、`Lite` 或工具栏等小型细节。这些元素在 Dock、任务栏和文件关联的小尺寸场景中会变成噪点，也容易与通用文本编辑器图标混淆。

## 2. 图形结构

- 画布：`1024 x 1024`，外部透明。
- 主体：`848 x 872` 的圆角应用块，四周保留阴影和平台裁切空间。
- 标记：三笔圆角 `N`；两条深色竖笔稳定图形，青蓝对角笔画表达编辑动作和 Nolia 家族关系。
- 安全区：核心标记保持在画布中央约 `280-744px` 范围内；平台遮罩不得裁切标记。
- 禁止：在母版外围再加白色方底、为 Windows/Linux 单独移动标记、叠加版本角标或文字。

## 3. 色彩

| 名称 | 色值 | 用途 |
|---|---|---|
| Ink light | `#26384B` | 深色骨架起点 |
| Ink dark | `#122033` | 深色骨架终点 |
| Teal | `#20B8A9` | 对角笔画起点 |
| Blue | `#0B83D0` | 对角笔画中段 |
| Deep blue | `#155DCC` | 对角笔画终点 |
| Paper | `#FFFFFF` → `#DCE7EC` | 应用块表面 |

这些颜色独立于界面主题。系统深色模式下不反转图标，也不替换为深色底版本。

## 4. 尺寸策略

- `128px` 及以上：保留表面边缘、顶部高光和两层阴影。
- `32-64px`：优先检查 `N` 的三笔是否仍分离，背景高光可以弱化但不能改变标记比例。
- `16-24px`：只要求轮廓、深色竖笔和青蓝对角笔画可辨；不添加像素级新细节。
- macOS、Windows、Linux、iOS 和 Android 资源全部由同一 SVG 母版生成，避免平台版本漂移。

## 5. 导出

使用 Tauri CLI 从母版生成资源：

```sh
npx tauri icon src-tauri/icons/app-icon.svg
```

生成后至少检查 `icon.png`、`128x128.png`、`32x32.png`、`icon.icns` 和 `icon.ico`。发布包必须重新构建，确认操作系统缓存之外的安装产物已经包含新图标。
